Fortivia — static export for fortivia.co.ke
====================================================
This folder is your whole site as plain HTML files.

To make it live at https://fortivia.co.ke (FREE, no card):

1. Go to https://pages.cloudflare.com  -> Log in (or create free account)
2. Click "Create application" -> "Pages" -> "Upload assets"
3. Drag this ENTIRE folder (fortivia-static) into the browser
   — or drag the ZIP and Cloudflare will unzip it.
4. After it uploads, click "Deploy".
5. Go to Custom domains -> Add "fortivia.co.ke" and "www.fortivia.co.ke"
   Cloudflare tells you what to change at your domain's DNS -> save -> wait 5 mins.

Your links will then be:
  https://fortivia.co.ke               (home)
  https://fortivia.co.ke/adventures
  https://fortivia.co.ke/interiors
  https://fortivia.co.ke/agri
  https://fortivia.co.ke/trips/1 etc.

Note: forms/bookings/admin need the Rails app. They still work at your
LlamaPress link https://rails-leo-kuuka.leo.llamapress.ai/admin
Edit there, then re-export this static ZIP when you update.
